# 会话连续性验证记录（2026-08-14）

## 结论
DSH Web API（127.0.0.1:3080）支持**会话复用 + 上下文记忆**，已实测验证：
- `session.create` → 返回持久 sessionId（如 `session-42004a27-...`）
- `session.prompt {sessionId, mode:'queue', content:[{type:'text',text}]}` 追加消息到该会话
- `session.history {sessionId}` 轮询取结果
- 同一会话第二条消息能引用第一条内容（"记住苹果"→"我刚才让你记住什么？"→"苹果"✅）

## 对实现的意义
Agent D 正在改造 `src/executor.js`：Web API 后端维护 sessionId 注册表（持久化 sessions.json），
`POST /api/exec {task, sessionId}` 复用会话实现"手机上继续对话"。

## 注意点
- mode='queue' 的 prompt 是排队执行，轮询 history 直到 turn/end
- history 事件含 assistant/message（content 里 type:'text' 块为正文）
- 会话有 406 个事件（含系统消息），提取文本需过滤 type:'text' 且 role=assistant

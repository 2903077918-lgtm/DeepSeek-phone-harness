# 关于"手机远程控制 Agent"，你最关心的 10 个问题，一次说清

> 收集了评论区和我自己常被问到的 10 个问题，统一回答。看完你就能判断：这东西适不适合你。

---

做 [DeepSeek Phone Harness](https://github.com/2903077918-lgtm/DeepSeek-phone-harness) 以来，被问得最多的问题翻来覆去就是这 10 个。今天一次说清。

## Q1：手机远程控制电脑上的 Agent，安全吗？

**看你怎么用。** 项目本身做了两层保护：所有接口要 Bearer Token；危险操作会先弹「需要授权」卡，由你在手机上决定放行或拒绝。但**任何远程控制工具的安全上限，取决于你的网络**——建议用 Tailscale 这类私有网络，不要把 8788 端口裸暴露到公网。

## Q2：需要公网 IP 吗？要买服务器吗？

**都不用。** 4G/5G 走 Tailscale 直连电脑（免费），局域网直接连。想要公网入口也有 Cloudflare Worker 方案，可选。

## Q3：和"远程桌面"（向日葵/ToDesk）有什么区别？

远程桌面是"看屏幕、动鼠标"，**传输的是画面**；这个是"发指令、看结果"，**传输的是语义**。手机上看的是 Agent 的推理、工具调用、结果——不是一坨缩小的屏幕。流量小一个数量级，手机上体验也清晰得多。

## Q4：手机端和网页端体验差多少？

功能上覆盖网页端绝大部分：对话、流式、模型切换、图片附件、审批、提问、终端、文件、任务。细节上手机端有几个网页端没有的优势：**审批/提问卡片直插消息流**（不打断上下文）、**工具调用是纵向时间线**（天然适合竖屏）。重活（改大量代码）当然还是电脑舒服。

## Q5：任务会卡死吗？Agent 反问怎么办？

以前会——这正是我踩过的最大的坑。Agent 调用 `ask_user_question` 反问时，如果没人回答，任务永远挂着。现在反问会变成手机上的「需要你回答」卡片：**选选项 / 打自定义答案 / 跳过**，答完继续跑，不答就等着。任务永远不会"没人理"。

## Q6：手机上能看到 Agent 具体在干什么吗？

能，而且这是我最自豪的部分。每一步工具调用是一张**工具卡片**：

```
[📄 read]                          ● 完成
C:/Users/Joey/Documents/.../config.json
▾ 点击展开：完整参数 + 完整结果
```

读哪个文件、执行什么命令、结果如何，全看得见。Agent 的思考过程也折叠展示。

## Q7：4G/5G 真能流畅用吗？

能。流式输出是增量轮询，每次只拉新增的几百字节；工具卡片、审批卡都是轻量 JSON。实测 4G 网络下打字机效果流畅。

## Q8：要装 App 吗？要配置什么？

**不用装 App**——手机浏览器直接打开一个网页（支持 PWA 添加到主屏幕）。电脑端只要 Node 22+ 和已运行的 DeepSeek Harness。配置就一个 `config.json` 填令牌。

## Q9：零依赖是真的吗？好部署吗？

真的。Agent 只用 Node 内置模块（http / child_process / crypto / fs），**没有任何 npm 依赖**。克隆 → 填令牌 → `node agent.mjs --mode=both`，跑起来。前端就一个 `relay.html` 文件。

## Q10：它和 DeepSeek 官方是什么关系？

**纯社区项目，非官方。** 我纯粹觉得"手机控制电脑 Agent"这个需求该有人做，就做了。官方在做的是 Harness 本身，我做的是它的"口袋版遥控器"。

## 结论

适合你吗？一句话判断：**如果你经常"人不在电脑前但想让 Agent 干活"，它适合你；如果你永远坐在电脑前用 Agent，那它只是锦上添花。**

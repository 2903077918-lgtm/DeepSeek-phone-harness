• Direct 4G/5G via Tailscale (free)
• Tool-call cards with file paths, status & expandable details
• Approval & question cards — tasks never deadlock
• Model switching, image attachments, terminal, file browser

🚀 Try it (3 min)
git clone https://github.com/2903077918-lgtm/DeepSeek-phone-harness
cd DeepSeek-phone-harness && cp config.example.json config.json
node agent.mjs --mode=both

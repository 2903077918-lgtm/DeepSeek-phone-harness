# 我手机上最常用的 5 个 Agent 任务：一个真实的使用清单

> 不聊概念，聊清单。这是过去一周我用手机给电脑上的 Agent 派过的活，全部真实。

---

做了 [DeepSeek Phone Harness](https://github.com/2903077918-lgtm/DeepSeek-phone-harness) 之后，我养成了一个习惯：**凡是能手机搞定的事，绝不起身去书房。** 这是过去一周真实的手机操作记录。

## 任务 1：通勤路上派活，到站收结果

最常用。地铁上打开手机，给 Agent 发"把 downloads 里最大的 5 个文件列出来，按大小排序"，到站打开手机看结果。

**手机端体验**：发完就锁屏。Agent 在电脑上慢慢跑，我在地铁上慢慢晃。工具卡片显示它正在 `dir`、正在 `du`，每一步都在眼皮底下。

## 任务 2：睡前改参数，醒来已验证

晚上躺床上，给 Agent 发"把 config 里的超时时间改成 30 秒，改完跑一遍测试"。第二天醒来，测试已经跑完，结论在手机上躺着。

**为什么在手机上做**：因为我要关灯睡觉了。这个任务要是只能电脑操作，我大概率会拖到第二天忘掉。

## 任务 3：开会时点审批

Agent 干到一半需要授权——这种场景以前只能等回到电脑前。现在手机弹「需要授权」卡，**拇指点一下「允许一次」**，它继续跑。

**最爽的一刻**：同一张桌子的同事问我"你在会上干什么"，我说"给电脑上的 Agent 放行"。

## 任务 4：临时查代码

躺沙发上，突然想确认某个文件里有没有某个函数。以前：起身 → 书房 → 打开编辑器 → 搜 → 回来。现在：手机打开 → 文件页翻到那个文件 → 看完 → 继续躺。

**工具卡片在这时候尤其有用**：Agent 搜代码时，卡片直接显示它在读哪个文件，路径一目了然。

## 任务 5：模型选择实验

想对比 deepseek-v4-flash 和 v4-pro 在同一个任务上的表现——手机上点顶部模型名，切换，重发任务，并排看结果。

**以前**：命令行改配置、重启、再试。**现在**：两次点击。

## 一个共同点

这 5 个任务有个共同特征：**都不需要"人在电脑前"**。它们只需要：

1. 能发指令
2. 能看到过程
3. 能在关键时刻做决策（审批/回答）
4. 能收结果

手机恰好全都能给。而"人不在电脑前"恰恰是 Agent 场景里最被忽略的一块。

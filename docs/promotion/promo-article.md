# 把 DeepSeek Harness 装进口袋：手机 4G 远程控制电脑上的 Agent

> 开源项目 **DeepSeek Phone Harness** —— 在手机上完整复刻 DeepSeek Harness 的工作体验：对话、模型切换、工具调用审批、终端、文件浏览，随时随地。

---

## 先讲个场景

凌晨一点，你躺在床上，电脑在书房跑着一个 DeepSeek Harness 任务。突然你想：让它顺手把那个重构也做了吧。于是你爬起来、走到书房、打开电脑、输入指令、等它跑完、看一眼输出、再回床上——**就为了发一句话，你花了两分钟走了一趟**。

如果这时候你只需要掏出手机，打开一个页面，发消息、看流式输出、批准工具调用、甚至回答 Agent 的反问，然后继续躺着呢？

这就是我做 **DeepSeek Phone Harness** 的动机：**把 DeepSeek Harness 装进口袋**。

## 这是什么

DeepSeek Phone Harness 是一个开源的手机端远程控制系统。它让手机在任何网络下（4G/5G / WiFi / 公网）远程操作电脑上的 DeepSeek Harness：

- 给电脑上的 Agent 派发任务，**流式**看它干活
- 查看每一步**工具调用**：做了什么、操作了哪个文件、结果如何
- 危险操作**审批**：允许 / 拒绝
- Agent 反问时**回答提问**，任务不会被卡死
- 切换**模型**、发**图片附件**、看**思考过程**
- 跑**终端命令**、翻**文件代码**、查**任务记录**
- 完全对标 DeepSeek Harness Web GUI 的工作体验

界面参考了开源项目 codex-relay 的设计语言（深色、卡片化、金色鲸鱼标识），对话体验对齐 DSH 原生界面。

## 上手体验：就像在用 DSH 本身

### 对话，和电脑上一样

手机端打开就是对话界面，支持多轮会话、Markdown 渲染、流式打字机输出。顶部可以**切换模型**（deepseek-v4-flash / v4-pro 等多个 Provider），输入框旁有 **+ 添加图片**，发图给 Agent 分析。

### 每一步操作都看得见

这是我觉得最值的地方——**工具调用卡片**：

```
[📄 read]                        ● 完成
C:/Users/Joey/Documents/.../config.json   ← 路径一目了然
▾ 点击展开：
  参数  {"file_path": "...", "limit": 1}
  结果  <path>... 1: {
```

图标区分工具类型（write/read/终端/web/子代理…），状态实时切换（执行中转圈 → 完成绿点 / 失败红点），**操作的文件路径直接显示**，点卡片还能看完整参数和结果。Agent 的**思考过程**也折叠展示，流式时自动展开——你看着它一步步想、一步步做。

### 审批与提问，一个都不卡

DSH 的 Agent 会请求授权、也会反问用户。手机端对应两张卡：

- **需要授权**：允许一次 / 拒绝
- **需要你回答**：选项选择 / 自定义输入 / 跳过本题

不回就等，回完继续跑——**任务永远不会因为没人回答问题而卡死**。

### 终端、文件、任务，全套远程

- **终端**：手机执行电脑命令，流式输出，中文正常，可停止
- **文件/代码**：浏览电脑目录、查看文件内容
- **任务列表**：历史任务回看、展开输出、一键重跑
- **会话管理**：多工作区切换、新建 / 重命名 / 删除 / 搜索

## 技术上有意思的地方

- **纯 Node.js 零依赖**：Agent 端没有装任何 npm 包，HTTP 传输 + DSH Web API RPC 封装 + events.mux WebSocket 中继，全是 Node 原生能力
- **单文件前端**：`relay.html` 一个文件搞定全部界面，无框架，手机浏览器直接打开
- **事件流复用**：一条 WebSocket 连接同时收审批、提问、会话事件，前端增量轮询做打字机效果
- **云端可选**：Cloudflare Worker 托管前端 + 可选 E2EE 任务通道，4G/5G 直连电脑走 Tailscale 即可

## 三分钟跑起来

```bash
# 电脑端（需已运行 dsh web，监听 127.0.0.1:3080）
cp config.example.json config.json   # 填访问令牌
node agent.mjs --mode=both
```

手机打开 `http://<电脑Tailscale IP>:8788/`，输入地址和令牌，选工作区，开工。

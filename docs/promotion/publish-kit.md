## 四、各平台格式适配

### 掘金（Markdown ✅）
- 直接粘贴 md 文件，编辑器自动渲染
- 首行加封面图建议（可先用仓库 Logo/截图占位）
- 结尾固定：`如果对你有帮助，欢迎 Star：<仓库链接>`

### V2EX（类 Markdown ⚠️）
- 正文用 `promo-article.md` 精简版（**去掉表格**，V2EX 不支持）
- 标题即主题，正文前 3 行必须抛出痛点
- 结尾留链接 + 一句"求 Star 求反馈"
- 注意：V2EX 不能纯广告，标题带「开源/分享创造」节点

### CSDN（Markdown ✅）
- 直接粘贴；**必须原创声明**（CSDN 要求）
- 标题加 `（附完整源码）` 类关键词提升搜索
- 文末附目录结构 + 快速开始代码块

### 知乎（纯文本 ⚠️）
- 不支持 Markdown，用 `viral-1`/`viral-5` 改写为分段纯文本
- 标题≤30 字：`把 DeepSeek Harness 装进口袋：手机远程控制 Agent`
- 首段必须 3 秒钩子（深夜场景）
- 链接放文末（知乎对站外链接有流量限制，正文引导"评论区/搜索项目名"）

### dev.to（Markdown ✅）
- 直接粘贴 `.en.md`
- 封面图建议 1000×420（可在仓库 README 截一张）
- 标签最多 4 个：`deepseek` `opensource` `node` `productivity`

### Reddit（Markdown ✅ 分帖）
- **Show HN**（r/SomebodyMakeThis / r/selfhosted）：`Show HN: ...` 标题 + 简短正文 + 链接
- **r/LocalLLaMA**：发 `en-tech-deep.md`（技术向）
- **r/opensource**：发 `en-open-source.md`（理念向）
- 注意：Reddit 自推需遵守各 sub 规则，建议先参与讨论再发

### Hacker News（纯标题 + URL）
- 标题：`Show HN: Zero-dependency phone remote for DeepSeek Harness`
- 提交 URL：仓库链接；**正文不能发**（HN 只有标题+链接）
- 标题是唯一武器，必须 80 字符内讲清"是什么+亮点"

## 五、发布节奏建议

- 同一内容**不要同一天全平台发**，错开 1–2 天（防判定 spam）
- 发布后 1 小时内回复所有评论（平台算法加权）
- 每个平台的主标题微调，避免搜索引擎判重复
- 一周节奏：2 篇中文 + 1 篇英文

# DeepSeek Harness 出门就废？我做了个开源项目，让它在 4G 网络下也能随叫随到

> 电脑上的 Agent 再强，你不在电脑前它就等于不存在。直到手机也能指挥它。

---

先说结论：**这个帖子是来"打脸"的——打我自己之前的脸。**

我一直觉得 DeepSeek Harness 很好用，直到有一天我在外面，突然想让电脑上的 Agent 帮我整理一份资料。然后我意识到一个残酷的事实：

> 我人不在电脑前，Agent 就是摆设。

你在公司、在通勤、在吃饭、在躺平——**任何离开电脑的瞬间，你都用不上它**。这合理吗？不合理。所以我动手了。

## 我做了什么

做了一个开源的手机端远程控制项目，让手机在任何网络下操作电脑上的 DeepSeek Harness：

- **4G/5G 直连**（走 Tailscale，免费），不用公网 IP
- **实时流式输出**——Agent 说的话，手机上一个个字蹦出来
- **工具调用全程可视**——读了什么文件、执行了什么命令、结果如何，一张卡片全看清
- **审批 + 问答**——要授权弹卡，要提问弹卡，任务永不卡死
- **模型随便切**、**图片随便发**、**终端随便敲**、**文件随便翻**

## 它有多轻

整个 Agent **零 npm 依赖**，4000 行左右。前端一个 HTML 文件。

没有云服务器、没有数据库、没有框架、没有 `npm install`。**克隆 → 填个令牌 → 跑起来**，就这么简单。

## 实测场景（都是真事）

**场景一**：地铁上，手机打开页面，给电脑 Agent 发了个任务。到站时，结果已经在手机上了。

**场景二**：Agent 干活到一半要授权——以前这种情况我只能干等。现在手机上弹卡，点「允许一次」，它继续。

**场景三**：Agent 突然反问我一件事。手机卡片上选个选项，任务接着跑。**以前遇到反问，任务基本等于卡死；现在 10 秒解决。**

## 三分钟跑起来

```bash
git clone https://github.com/2903077918-lgtm/DeepSeek-phone-harness
cd DeepSeek-phone-harness && cp config.example.json config.json
node agent.mjs --mode=both
```

手机 Tailscale 连上电脑，打开 `http://<电脑IP>:8788/`，输入令牌，开干。

## 说点实话

它当然还有不足：目前是网页版（不是原生 App），命令执行是逐个跑（没有完整 PTY 交互），云端通道还需要自己部署 Worker。**但"手机上能完整控制电脑 Agent"这件事，已经做到了，而且是开源免费的。**
